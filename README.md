# 🚀 TechWave Podcast | Responsive Web Project
This is a clean, modern web project where I focused on building a seamless user experience from scratch. My main goal here was to master responsive layouts and ensure that the interface looks sharp and professional across all devices, from mobile screens to large desktops.

## 🛠️ Tech Stack & Tools
To keep the development fast and the design consistent, I used:
* **HTML5** - For a solid semantic foundation.
* **CSS3** - To handle custom styles and fine tune the visuals.
* **Tailwind CSS** - My go to utility first framework for building the layout quickly without leaving the HTML.
* **Google Fonts** - Specifically chosen to give the UI a modern readable feel.

## ✨ Key Features
* **Adaptive Layout:** I used Tailwind’s breakpoints to make sure the site feels native on mobile, tablet, and desktop.
* **Clean UI:** Focused on white space and typography to keep the interface distraction free.
* **Interactivity:** Added smooth hover states and transitions to make the site feel alive and responsive to user actions.
* **Fast & Lightweight:** Since I used a utility first approach the site loads quickly without unnecessary bloat.

## 📦 Libraries Used
I kept things simple by pulling in these reliable resources:
* **Tailwind CSS** (for the core styling)
* **Font Awesome** (for scalable icons)
* **Google Fonts** (for professional typography)
